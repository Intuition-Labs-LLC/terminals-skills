# /recommend (OpenCode)

You decide. The user is unsure, so take the wheel. Run the whole loop yourself and come back with a pick and the receipt.

Problem: **$ARGUMENTS**

1. **Explore (you).** Up to 7 genuinely distinct strong angles, your real conviction.
2. **Judge agreement.** Rate every pair 0..1, honestly. Build the coherence matrix.
3. **Run the loop.** Call the `terminals` MCP tool `recommend` with `{ ideas, coherence }`. It converges, then optimizes, and returns pick plus alternatives plus witness.
4. **Make the call.** Your pick in one or two plain sentences. State it directly.
5. **Back it.** The receipt: which trios lock the pick, the meters, 1 or 2 alternatives with the one reason each lost. The receipt certifies coherence given your judgments; it does not prove the pick is correct in the world. Partial means "I can't fully back a pick yet" plus the lean plus the one thing that would settle it.

Pick first, receipt second. State the call directly.
