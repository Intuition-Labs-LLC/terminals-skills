# /recommend (OpenCode)

You decide. The user is unsure — take the wheel. Run the whole loop yourself and come back with a pick and the receipt.

Problem: **$ARGUMENTS**

1. **Explore (you)** — up to 7 genuinely distinct strong angles, your real conviction.
2. **Judge agreement** — rate every pair 0..1, honestly. Build the coherence matrix.
3. **Run the loop** — call the `terminals` MCP tool `recommend` with `{ ideas, coherence }`. It converges, then optimizes, and returns pick + alternatives + witness.
4. **Make the call** — your pick in one or two plain sentences. Don't hedge.
5. **Back it** — the receipt: which trios lock the pick, the meters, 1–2 alternatives with the one reason each lost. Partial → "I can't fully back a pick yet" + the lean + the one thing that'd settle it.

Pick first, receipt second. No fence-sitting.
