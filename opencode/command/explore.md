# /explore (OpenCode)

Open it up. Spread the question into every distinct angle. Width, not an answer.

Question: **$ARGUMENTS**

1. **Fan it out** — up to 7 genuinely different angles, each able to stand alone.
2. **Keep them apart** — merge near-duplicates, find fresh ones.
3. **Score the spread** — call the `terminals` MCP tool `explore` with `{ ideas, question }` for the divergence score.
4. **Hand them back** — a clean numbered list, one line each, with what each bets on and risks.
5. **Point onward:** "to land on one, /converge; to have me decide, /recommend."

Do not converge here. Leaving it open is the job.
