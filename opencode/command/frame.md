# /frame (OpenCode)

Start from the user's own context. Pull it in, translate it, pick up from there.

Where it lives: **$ARGUMENTS** (empty or "here" → the current folder + this conversation).

1. **Read their stuff** — read the path/files named, or scan the working folder; skim for the distinct claims and options.
2. **Pull out the items** — the distinct ideas/options/claims; aim for the 7 that weigh most.
3. **Translate** — call the `terminals` MCP tool `frame` with `{ items }` (add coherence if you can judge how they fit). It maps each onto the 7-grid and converges.
4. **Show the reading first** — "here's how I read your stuff", each item → its place, so a misread gets caught early.
5. **Then the answer + receipt**, like converge. Partial → what's loose + the next step.

Read first, translate openly, then converge.
